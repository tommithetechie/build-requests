### The rules (loosely)

- Credit goes to whoever suggested it. You'll get tagged when it ships.
- Nothing harmful, nothing sketchy, nothing that needs anyone's private info.
- "Nope" usually means too big, too risky, or I'm not ready yet. Ideas can come back.
- If it's broken, it's probably on purpose. Probably.

*Build weird stuff. Learn out loud. Stumble forward.*
